======================================================================
ОБЪЯСНЕНИЕ РАЗЛИЧИЙ МЕЖДУ ТИПАМИ ВЫБОРОК
======================================================================

1. ВЫБОРКА С ВОЗВРАЩЕНИЕМ:
   • Элемент после выбора возвращается обратно в множество
   • На каждом шаге доступны все n элементов
   • Элементы могут повторяться в выборке
   • Количество возможных выборок: n^m
   • В матрице: в каждом столбце может быть несколько единиц

2. ВЫБОРКА БЕЗ ВОЗВРАЩЕНИЯ:
   • Выбранный элемент удаляется из множества
   • Каждый элемент может быть выбран не более одного раза
   • Все элементы в выборке различны
   • Количество возможных выборок: n!/(n-m)!
   • В матрице: в каждом столбце не более одной единицы

3. РАЗМЕЩЕНИЕ (m = n):
   • Частный случай выборки без возвращения
   • Выбираются все n элементов в некотором порядке
   • Получается перестановка из n элементов
   • Количество возможных перестановок: n!
   • В матрице: ровно одна единица в каждой строке и каждом столбце
